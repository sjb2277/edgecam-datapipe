# Week 5 · 폐루프 제어와 마무리 (11/30 ~ 12/4)

주간 목표: 측정 결과로 만든 적응 정책이 송신 설정을 바꾸는 폐루프를 완성하고 on/off A/B로 효과를 검증하며, repo를 처음 보는 사람이 5분 안에 이해하고 재현할 수 있게 정리한다.
참고: 규칙은 루트 `CLAUDE.md`, 개요·스택·포트·데이터 계약은 `overview.md`, 부품·시나리오는 `hardware.md`.

### D21 · 11/30(월) · 설정 스윕과 권장 설정표

- 작업
  1. 설정 3단계(해상도·fps·x264 비트레이트) × 링크 시나리오 4종(정상, 손실 고, 대역 제한, 지연+지터 혼합) × 3회 = 36 run을 `make sweep`으로 클립 재생 실행(소요 시간은 D16 실측으로 조정)
  2. 설정 × 시나리오별 진입 검출률·감지 지연으로 임계점 탐색 → 권장 설정표(링크 상태별로 기준 대비 검출률을 허용 기준 이상으로 유지하는 최소 설정)
  3. 감지 지연의 이동 거리 환산 열 추가(속도 30·50km/h, 감지가 늦어진 거리일 뿐 제동 거리 전체가 아님을 표기)
- 완료 기준: 설정 × 시나리오 권장 설정표 1장
- 기록: 허용 기준(기준 대비 검출률을 몇 % 이상으로 볼지)을 정한 근거 (본인 설계)

### D22 · 12/1(화) · 적응 정책과 제어 경로

- 작업
  1. `control.command`, `control.ack` 스키마 등록(D05 절차: 상속, 등록 스크립트, BACKWARD). 카메라 송신 agent와 ESP32를 구분하는 대상 필드는 ADR-0011에서 결정
  2. 정책 컨트롤러: `link.metrics`·`net.probe`로 상태 판정(D13 `network_state`와 같은 임계값을 온라인용으로 구현) → 권장 설정표 조회 → 송신 파이프라인(해상도·fps·x264 비트레이트)에 변경 명령 → ack. 하향은 즉시, 복귀는 N초 안정 후(히스테리시스)
  3. `cmd_id` 기반 중복 명령 무시, 타임아웃·재시도
  4. (선택, 여유 시) 구역 진입 이벤트 → ESP32 LED·부저
- 완료 기준: 열화 주입 시 설정이 바뀌고 회복 시 복귀, 명령 왕복 지연 분포(정상·열화)
- 기록: ADR-0011 정책 규칙·임계값·히스테리시스 결정 과정(본인 설계), 재시도 정책과 멱등 처리
