# Week 5 · 폐루프 제어와 마무리 (11/30 ~ 12/4)

주간 목표: 데이터가 실제 장비 동작으로 이어지는 폐루프를 완성하고, repo를 처음 보는 사람이 5분 안에 이해하고 재현할 수 있게 정리한다.
참고: 규칙은 루트 `CLAUDE.md`, 개요·스택·포트·데이터 계약은 `overview.md`, 부품·시나리오는 `hardware.md`.

### D21 · 11/30(월) · 제어 경로

- 작업
  1. `control.command`, `control.ack` 스키마 등록(D05 절차: 상속, 등록 스크립트, BACKWARD)
  2. 엣지 컨트롤러 → 링크 → device-gateway → ESP32 시리얼 명령 → ack 회신
  3. `cmd_id` 기반 중복 명령 무시, 타임아웃·재시도
- 완료 기준: 명령 100회 왕복 지연 분포, 시나리오별(정상·열화) 비교
- 기록: 재시도 정책과 멱등 처리

### D22 · 12/1(화) · 폐루프 시나리오와 A/B

- 작업
  1. 시나리오 1: 사람 검출 + 거리 임계 이하 → LED·부저
  2. 시나리오 3: `network_state=열화` → V4L2로 해상도·fps 하향, 회복 시 복귀
  3. 적응 제어 on/off를 같은 링크 시나리오에서 A/B 실행
  4. 시나리오 2(서보 추적)는 시간이 남을 때만 한다
- 완료 기준: 적응 전후 드롭률·지연·검출 일치율 비교표
- 기록: 임계값과 히스테리시스(상태 진동 방지) 결정 과정
