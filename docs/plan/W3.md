# Week 3 · 정제와 배치 (11/16 ~ 11/20)

주간 목표: run 하나가 끝나면 정제된 분석 테이블과 품질 리포트가 자동으로 나온다.
결정 게이트 G3(D15): 일부러 깨뜨린 run이 격리되는지 확인한다.
참고: 규칙은 루트 `CLAUDE.md`, 개요·스택·포트·데이터 계약은 `overview.md`.

### D11 · 11/16(월) · dbt 프로젝트와 silver 1

- 작업
  1. dbt-core + dbt-postgres 세팅, `sources.yml`에 bronze 등록
  2. `silver.frames`: 송신⋈수신(RTP ts), 프레임별 e2e 지연, 드롭 여부
  3. dbt tests: unique, not_null, accepted_values, relationships
- 완료 기준: `dbt build` 통과, run 1개의 프레임 드롭률이 D02 스크립트 값과 일치
- 기록: 모델 계층 명명 규칙

### D12 · 11/17(화) · silver 2: 시간 정렬

- 작업
  1. `silver.link_1s`, `silver.probe_1s`, `silver.device_1s`: `time_bucket`으로 1초 집계
  2. `silver.detections` 정리(클래스 필터, 신뢰도 임계)
  3. 늦게 도착한 이벤트 처리 규칙 결정: event_ts 기준 집계 + 허용 지연
- 완료 기준: run 1개를 1초 단위로 정렬한 테이블 생성
- 기록: ADR-0006 시간 기준(event_ts vs ingest_ts)

### D13 · 11/18(수) · gold: 피처와 자동 라벨

- 작업
  1. `gold.run_second_features`: 초당 fps, p95 지연, 드롭률, 검출 수, 링크 설정·지표, 장비 상태
  2. 자동 라벨 `network_state`(정상·열화·단절) 규칙 기반, `label_version` 컬럼
  3. 샘플 원본 프레임에 reference 추론 → 수신 프레임 검출과 IoU 매칭 → 검출 일치율
  4. `gold.run_summary`: 시나리오 단위 요약
- 완료 기준: 시나리오 3개의 요약 비교표
- 기록: 라벨 임계값을 정한 근거(측정 분포 그래프)

### D14 · 11/19(목) · Airflow 오케스트레이션

- 작업
  1. Airflow LocalExecutor 경량 compose(`batch` 프로파일). 메모리 4GB 이상 필요하므로 exp 프로파일과 동시에 띄우지 않는다
  2. DAG `run_postprocess`: check_run_complete → validate_bronze(pandera) → reference_inference → dbt_build → quality_report
  3. `pipe run stop` 시 Airflow REST API로 DAG 트리거
- 완료 기준: run 종료 → DAG 자동 성공, 재실행해도 결과 동일
- 기록: 태스크 분리 기준, 재시도 정책

### D15 · 11/20(금) · 품질 리포트 자동화 (게이트 G3)

- 작업
  1. 품질 지표: seq 갭, 타임스탬프 역전, 중복률, 결측률, DLQ 건수(producer/loader 구분), 적재 지연 p95, 스키마 위반
  2. `reports/runs/<run_id>.md` 자동 생성 + `meta.quality_reports` 저장
  3. 임계값 위반 run은 `quarantined` 상태로 표시, gold 집계에서 제외
  4. 깨진 run 2종 주입: 필드 누락 메시지, 대량 손실 시나리오
- 완료 기준: 깨진 run 2종이 모두 격리된다
- 기록: 품질 임계값 표
