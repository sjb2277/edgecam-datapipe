# Week 4 · 재현성과 서빙 (11/23 ~ 11/27)

주간 목표: 누구든 한 명령으로 실험을 재현하고, 웹에서 run과 데이터셋을 비교한다.

참고: 규칙은 루트 `CLAUDE.md`, 개요·스택·포트·데이터 계약은 `overview.md`.

### D16 · 11/23(월) · 시나리오 매트릭스 실행

- 작업
  1. 시나리오 6개 정의: 정상, 지연, 지터, 손실 저·고, 대역 제한 (+G1에서 채택 시 rfsim 1개)
  2. 시나리오별 3회 반복 자동 실행: `make matrix`
  3. 실행 순서: exp 프로파일로 실행 → 종료 후 batch 프로파일로 정제
- 완료 기준: run 18개 이상 적재, 전부 품질 리포트 보유
- 기록: 반복 간 편차, 시나리오별 결과 요약

### D17 · 11/24(화) · 재처리와 스키마 진화

- 작업
  1. `pipe replay --run <id>`: MinIO raw → bronze 재적재 → dbt 재실행
  2. replay 전후 gold 테이블 체크섬 비교
  3. 스키마 v2(선택 필드 추가) 등록, Schema Registry 호환성 모드 BACKWARD로 v1 consumer가 깨지지 않는지 테스트
- 완료 기준: replay 전후 gold 체크섬 동일, v1·v2 혼재 적재 성공
- 기록: ADR-0007 스키마 진화 정책 (Avro 전환 여부 포함)

### D18 · 11/25(수) · 데이터셋 버전

- 작업
  1. DVC 초기화, MinIO를 remote로 지정
  2. 데이터셋 정의 YAML(쿼리, 필터, label_version) → Parquet + 샘플 이미지 + manifest(체크섬, 원천 run 목록)
  3. ds-v1(현재 라벨 규칙)과 ds-v2(라벨 임계값 변경) 생성, 차이 리포트
- 완료 기준: `dvc checkout`으로 v1·v2 각각 복원
- 기록: 데이터셋을 코드로 정의한 이유
- 일정이 밀리면 DVC 대신 체크섬 manifest로 줄인다.

### D19 · 11/26(목) · API

- 작업
  1. FastAPI: `/runs`, `/runs/{id}/summary`, `/runs/{id}/timeseries`, `/datasets`, `/quality/{run_id}`
  2. WebSocket `/live`: bronze 최신 이벤트 tail
  3. pytest 엔드포인트 테스트, OpenAPI 문서 확인
- 완료 기준: 테스트 통과, `/docs`에서 전 엔드포인트 호출 성공
- 기록: API 응답 스키마 설계
